🛒 Ecommerce Web App (React + Django + PostgreSQL)

A full-stack ecommerce web application where users can browse products, manage cart, and complete purchases. The system includes a powerful admin panel for managing products, orders, and users.

🚀 Features

👤 User Side
User registration & login/logout
Browse products
Add to cart
Checkout & payment flow
Order placement
Responsive UI

⚙️ Admin Panel (Django Admin)
Manage products (CRUD)
Manage users
View and manage orders
Backend data control

🧱 Tech Stack

Frontend

React (Vite)
JavaScript / CSS

Backend

Django
Django REST Framework

Database

PostgreSQL
